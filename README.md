# MCP Weather

MCP Weather is a simple weather application that provides current weather information for a given location. This project is designed to demonstrate the use of APIs and modern web development practices.

## Features

- Fetch current weather data for any location.
- Display temperature, humidity, and weather conditions.
- User-friendly interface.

## Installation

1. Clone the repository:

```bash
git clone https://github.com/your-username/mcp-weather.git
```

2. Navigate to the project directory:

```bash
cd mcp-weather
```

3. Install dependencies:

```bash
npm install
```

## Usage

1. Start the development server:

```bash
npm run dev
```

## Technologies Used

- React
